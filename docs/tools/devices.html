Device comparison: Si vs GaN vs SiC

Drop each transistor into the same flagship converter at the same operating point and switching frequency, so the only thing that changes is the device. The thermal column turns the hottest switch's loss into a junction temperature with the thermal resistance you choose.

Devices

The thermal resistance is your assumption (board copper, heatsink, airflow), not a datasheet value. Junction temperature is a one-pass estimate; the loss model itself assumes 80 C.
