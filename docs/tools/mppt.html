MPPT sandbox

The flagship's reference controller runs here tick by tick: the same state machine as the C and Python versions. It drives a simulated panel through clouds, partial shading and a filling battery. Watch it sweep, track, change mode and drop into bypass.

One tick = 1 ms. The first second is the start-up wait, so tracking efficiency counts from the first sweep. Converter efficiency comes from the flagship loss model, sampled every 50 ms.
