# Watt Forge desktop

The same web app as the GitHub Pages site, packaged with [Tauri 2](https://tauri.app) so it runs offline. It adds one thing the browser cannot do: **the SPICE runner executes netlists live in [ngspice](https://ngspice.sourceforge.io)**, inside a sandbox.

| Folder | What it is | Status |
|---|---|---|
| `netlist-guard/` | Pure-Rust validator for untrusted SPICE netlists. It rejects `.control`, `.include`, `.lib`, `shell`, oversize `.tran` and unknown elements. It shares one case file (`tests/fixtures/guard_cases.txt`) with the Python and JavaScript guards. | `cargo test`, no dependencies, runs in CI and `make test`. |
| `src-tauri/` | Tauri shell. It serves `docs/` from the bundle and runs with least privilege: `core:default` only, no fs, shell or http plugins. Designs are stored only in the app-data folder. `simulate_netlist` runs the guard, then ngspice in batch mode in a fresh temp folder with a 60 s limit and a 1 MB output cap. | **Built and smoke-tested on Ubuntu 24.04** (`.deb`, `.rpm`, `.AppImage`). CI builds Linux, Windows and macOS installers for every `v*` tag and attaches them to the GitHub release. |

## Get it

- **Easiest:** download an installer from the repository's **Releases** page. `docs/PUBLISH.md` has a one-paste Ubuntu block that installs the `.deb` from the release, or builds it locally if the release isn't ready yet.
- **Ubuntu/Debian:** `sudo apt install "./Watt Forge_0.1.0_amd64.deb"` also installs ngspice (it is a declared dependency). Launch **Watt Forge** from the app menu, or run `watt-forge-desktop`.
- **Windows / macOS:** the installers are unsigned. Windows SmartScreen and macOS Gatekeeper (right-click, then Open) will ask you to confirm. Install ngspice yourself (`brew install ngspice`, or the Windows build on PATH) to use the SPICE runner. Everything else works without it.
- **WSL2:** Ubuntu under WSL2 on Windows 11 shows Linux GUI apps through WSLg, so the `.deb` works there too.

## Build from source

```bash
# prerequisites (Ubuntu): Rust (rustup), then
sudo apt-get install -y build-essential pkg-config libssl-dev libwebkit2gtk-4.1-dev libgtk-3-dev librsvg2-dev patchelf ngspice
cargo install tauri-cli --version "^2" --locked     # once, about 10 minutes
make desktop          # = cd desktop/src-tauri && cargo tauri build  -> target/release/bundle/{deb,rpm,appimage}/
make desktop-dev      # run without installing
```

Icons are generated by `scripts/make_icons.py` (`make icons`), so no extra tooling is needed.

## End-to-end smoke test

```bash
WATTFORGE_SMOKE=1 xvfb-run -a desktop/src-tauri/target/release/watt-forge-desktop
# -> WATTFORGE_SMOKE PASS vavg=1.200000e+01 guard_rejected=true worker_eta=0.99940... page=/
```

With `WATTFORGE_SMOKE=1` the app loads its own page and makes two calls through the real page → IPC → guard → ngspice path. The first is an RC netlist, which must settle to 12 V. The second is a netlist containing `.control` and `shell`, which the guard must reject. Then it runs one MPPT benchmark in the control lab's module Web Worker, which proves workers run under the app's Content Security Policy. The app prints the verdict and exits with 0 or 1. Without the variable the `smoke_report` command does nothing. CI runs this on every Linux desktop build.

## Web vs desktop

| | Web (GitHub Pages) | Desktop |
|---|---|---|
| Lessons, tools, flagship, sources | yes | yes (same files) |
| Works offline | yes, once installed with the browser's "Install app" button (service worker) | yes, always |
| SPICE runner | guard check plus ngspice results stored at build time, presets only | live ngspice on any netlist that passes the guard |
| Control lab | live MPPT races in a Web Worker | the same, in the app's worker |
| Saved designs | browser storage | the webview's storage, kept per user |
